# 📊 NEIS 문항 분석 리포트 생성기

NEIS에서 내려받은 **성적·문항 파일**을 넣으면, 시각화된 **문항 분석 보고서**를 자동으로 만들어 주는 웹 프로그램입니다. 설치가 필요 없고, 파일 하나로 동작합니다.

> 🔗 **바로 쓰기:** `https://<내이름>.github.io/<저장소이름>/`
> (GitHub Pages 설정 후 위 주소가 활성화됩니다. 이 줄의 링크를 실제 주소로 바꿔 주세요.)

---

## ✨ 무엇을 만들어 주나요?

- **전체 현황** — 응시 인원·평균·최고/최저·표준편차 + 표준편차 해석
- **점수/등급 분포** — 히스토그램 + 5등급 상대평가 + **등급 컷 점수**
- **반별 평균 비교**
- **문항별 정답률** 그래프 & 분석 표(정답·배점·정답률·최다 오답·난이도)
- **오답 매력도(Distractor) 분석** — 어려운 문항의 선지별 응답 도넛
- **변별도 · 신뢰도(KR-20) · 문항 특성 지도** *(개인 정답표가 있을 때)*
- **문항별 등급 분석** — 문항 하나씩 골라 등급별(1~5) 정답률과 선지 선택 분포를 확인 *(개인 정답표가 있을 때)*
- **세특(생기부) 코멘트 초안 + 고난도 문항 정답자 명단** *(개인 정답표가 있을 때)*
- **시험 문제지 주석 PDF** — 문항 위에 정답률·변별도 배지를 표시한 PDF 다운로드 *(시험지 PDF도 함께 넣었을 때)*
- **결과분석 협의록 자료** — 평가결과 개요·반별 학급평균·성취수준별(A~E) 분포·예상 난이도 불일치 문항 표·임계값 계산기·의견 초안을 복사해서 교과협의록에 바로 붙여넣기 *(예상평균·문항별 예상난이도를 미리 입력해두면 자동 채워짐, 선택)*
- **PDF 저장/인쇄** 지원

## 🖱️ 사용법 (3단계)

1. 링크를 열거나 `index.html`을 더블클릭 (**크롬·엣지** 권장)
2. NEIS 엑셀 파일을 화면에 **끌어다 놓기** (여러 개 한 번에)
3. **[분석 리포트 생성]** 클릭 → 끝! (PDF 저장 버튼으로 저장)

## 📎 넣는 파일

| 파일 | 필요 | 추가로 생기는 분석 |
|---|---|---|
| 성취도 **성적 일람표** | 필수 | 전체 현황·점수/등급 분포·반별 비교 |
| **문항분석표** | 필수 | 문항별 정답률·오답 매력도 |
| 개인별 **정답표(정오표)** | 선택 | 변별도·신뢰도·등급별 정답률·세특 명단 |
| 문항정답표(정답률비교표) | 선택 | 반별 문항 정답률 |
| 문항정보표 | 선택 | 문항별 예상 난이도 자동 입력 (협의록 자료용) |
| 시험 문제지 **PDF**(한글에서 저장) | 선택 | 문항 위 정답률·변별도 배지 → 주석판 PDF 다운로드 |

> 가진 파일만 넣어도 됩니다. 없는 분석은 자동으로 생략됩니다.
